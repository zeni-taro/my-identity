# 言語学習の方針 (overview)

> 英語・スウェーデン語の学習にこのリポジトリを「参照先」として使うための共通ルール。
> 言語別の詳細は [language/english.md](english.md) / [language/swedish.md](swedish.md) を参照。

## このカテゴリの用途

- **文章の添削** — メール・Slack・ドキュメント等を自然な表現に直す。文体は [voice/](../voice/writing.md) を踏まえる。
- **会話・面接練習** — ロールプレイ・スピーキング相手。話題は [career/](../career/self-pr.md)・[thinking/](../thinking/values.md) を参照し自分の内容で練習する。
- **語彙・文法の学習** — 単語帳・文法説明・頻出ミスの記録と反復。言語別ファイルに蓄積する。

## 現状レベル（出典: [career/skills.md](../career/skills.md)）

- 日本語: Native / bilingual（説明・翻訳の基準言語）
- 英語: Professional working proficiency → 実務レベルの底上げ・自然さ重視
- スウェーデン語: Elementary proficiency → 基礎固め（基本語彙・文法・簡単な会話）

## AIへの依頼の仕方（共通）

- **レベル差を前提にする** — 英語は上級者向けにニュアンス・自然さ・誤りの指摘まで。スウェーデン語は初級者向けに平易な語彙・丁寧な解説・日本語での補足を厚く。
- **添削時** — ①直した版 ②主な修正点の理由 ③より自然な代替案、の順で返す。元の文体（[voice/writing.md](../voice/writing.md)）を尊重する。
- **会話・面接練習時** — 相手役になりきり、最後にフィードバック（良かった点・直すと良い点・自然な言い回し）をまとめる。
- **語彙・文法** — 新出・間違えた項目は言語別ファイルの「語彙・表現メモ」「頻出ミス」に追記する。
