# チャネル別トーン (by-channel)

> ⚠️ チャネル・相手ごとの文体の使い分け。値は本人確認後に記入。空欄は `（未記入）`。
> 詳細な基本ルールは [style/writing.md](writing.md) を参照。

| チャネル / 相手 | 文体 | トーン | 絵文字 | 備考 |
|---|---|---|---|---|
| 社内 Slack（チーム） | 常体・カジュアル寄り | カジュアル | 不可 | 感嘆符「！」は社内のみ可 |
| 社内メール（上長・他部署） | 敬体 | （未記入） | 不可 | |
| 顧客メール | 敬体 | 丁寧 | 不可 | |
| 顧客向け資料・ドキュメント | 敬体 | （未記入） | 不可 | |
| LinkedIn / 対外発信 | （未記入） | （未記入） | 不可 | |
| ブログ / 技術記事 | （未記入） | （未記入） | 不可 | |

## 使い分けの原則

- 社外（顧客・対外発信）は敬体を基本とする。社内（Slack等）はカジュアル寄りで可。
- 絵文字は社内外問わず使わない。感嘆符「！」は社内のみ可。
