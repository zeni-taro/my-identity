# my-identity

仕事で個人情報が必要になったとき（各種申請・提出書類・経費精算・出張手配など）に、**素早く・正確に・コピペで**参照するためのプライベート個人情報リポジトリ。

## 使い方

1. [INDEX.md](INDEX.md) で欲しい情報のカテゴリを探す。
2. 該当ファイルを開き、必要な値をコピペする。
3. 情報が変わったら即更新し、各ファイル末尾の `最終更新` を書き換える。

## 注意

- **マイナンバー・銀行口座番号・クレジットカード番号・パスポート番号** などの機密情報は一切記載しない（マスクも不可）。別途安全な手段（パスワードマネージャ等）で管理する。
- 方針・規約の詳細は [CLAUDE.md](CLAUDE.md) を参照。
